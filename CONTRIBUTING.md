# Cómo contribuir

Gracias por querer mejorar este repositorio.

- Abre un issue antes de enviar cambios grandes.
- Al enviar una contribución aceptas que se publique bajo las licencias del
  repositorio: MIT para el código (`LICENSE`) y CC BY-NC 4.0 para gráficos y
  tablas (`LICENSE-images`).
- No incluyas datos personales ni datos de terceros sin permiso de su titular, y
  documenta la fuente en `data/sources/`.
- Antes de enviar cambios, corre `python scripts/validate_chart_catalog.py`.
- El material elaborado por practicantes y colaboradores de LIDE para El
  Quantificador pertenece a LIDE.
